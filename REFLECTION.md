# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?

Building UI imperatively means we tell the browser what to do step by step .Declaratively means we tell React how we want the UI to look like,and React handles the steps.

2. Why must a component name start with a capital letter?

To tell React it is a component, not a normal HTML element.

3. What does a fragment <>...</> do, and why not just use a <div>?

fragment <>...</> group elements together without adding extra element to the HTML structure, like <div> does.

4. Name one benefit of splitting the UI into small components.

Code is easier to be understand and to be reuse.
